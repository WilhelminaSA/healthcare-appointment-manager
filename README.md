# Healthcare Appointment & Follow-up Manager

A healthcare appointment platform with separate portals for patients, doctors, and administrators.

## Tech Stack

- Frontend: React + Vite
- Backend: Flask
- Database: PostgreSQL
- ORM: SQLAlchemy
- Authentication: JWT
- Background Jobs: Celery
- Queue/Broker: Redis
- LLM: API-based LLM
- Email: SendGrid/Mailgun
- Calendar: Google Calendar API

## Project Status

Currently setting up Phase 0 and Phase 1.
